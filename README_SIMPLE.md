# RIOS - SUPER SIMPLE RUN (Windows)

1. Clone CORRECT branch:
```
git clone -b arena/019f67fb-arenatest-scaffolding https://github.com/Shresht-2009/arenaTest_Scaffolding.git
cd arenaTest_Scaffolding
```

2. Double-click `RUN_ME.bat`
- It will ask for GROQ_API_KEY (get free at console.groq.com) or press Enter for mock mode
- It installs deps and starts backend at http://localhost:8000 and frontend at http://localhost:3000

3. Open http://localhost:3000, enter problem, click START

Alternative: `python run.py`

Keep both black windows open.
